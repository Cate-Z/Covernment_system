---

## 📋 项目概述（2分钟）

### 一、项目背景
随着数字化转型的深入，政务部门对信息化系统的需求日益增长：
- 统一的用户管理体系
- 高效的内容发布流程
- 便捷的沟通反馈渠道
- 完善的安全审计机制

### 二、核心目标
1. **提升服务效率**：实现政务服务线上化
2. **强化安全管理**：完善的权限控制和操作审计
3. **促进信息公开**：新闻、博客等内容的及时发布
4. **优化用户体验**：响应式设计，多端适配

### 三、技术栈选择
| 层级 | 技术 | 选择理由 |
|------|------|----------|
| 后端框架 | Flask 2.3.3 | 轻量、灵活、易扩展 |
| 数据库 | MySQL 8.0.35 | 稳定可靠、政务系统首选 |
| 容器化 | Docker | 环境一致性、快速部署 |
| 前端 | HTML5 + CSS3 + JS | 无框架依赖、加载迅速 |

## 🏗️ 系统架构（2分钟）

### 整体架构图
```
┌──────────────────────────────────────────────┐
│              客户端（浏览器）                   │
│     http://虚拟机IP:5000                      │
└──────────────────────────────────────────────┘
                      │
                      ▼
┌──────────────────────────────────────────────┐
│      gov-portal-flask (Docker 容器)            │
│      Python Flask - Port 5000                 │
│  ┌────────────────────────────────────────┐   │
│  │  RESTful API + Jinja2 模板渲染         │   │
│  │  Session 会话管理 + 操作日志审计        │   │
│  └────────────────────────────────────────┘   │
└──────────────────────────────────────────────┘
                      │
                      ▼
┌──────────────────────────────────────────────┐
│      gov-portal-mysql (Docker 容器)           │
│      MySQL 8.0.35 - Port 3306                │
│  ┌────────────────────────────────────────┐   │
│  │  16张业务表 + Volume 数据持久化        │   │
│  └────────────────────────────────────────┘   │
└──────────────────────────────────────────────┘
```

### 核心模块
| 模块 | 功能说明 |
|------|----------|
| **统一认证** | 管理员/普通用户统一登录、注册 |
| **用户管理** | 用户CRUD、个人信息管理、最后登录时间 |
| **部门管理** | 动态增删改部门，注册可选 |
| **新闻管理** | 新闻发布、分类筛选、快速发布/草稿 |
| **博客系统** | 博客发布、审核流程、评论、点赞 |
| **反馈管理** | 反馈提交、处理回复、导出CSV |
| **系统监控** | 运行时间、请求计数、数据统计 |
| **操作日志** | 全操作审计、安全追溯 |

## 🚀 技术亮点（3分钟）

### 亮点一：Docker 容器化部署
- **一键部署脚本**：`setup.sh` 自动化部署
- **环境隔离**：应用与数据库独立容器
- **数据持久化**：Volume 保证数据不丢失
- **开机自启**：配置服务自动启动

### 亮点二：统一认证与权限控制
- **单点登录**：管理员与普通用户共用接口
- **角色权限**：基于角色的功能展示
- **Session管理**：安全的会话管理机制

### 亮点三：博客审核流程
- **权限分级**：管理员直接发布，普通用户需审核
- **状态流转**：pending → published/rejected
- **实时通知**：审核状态变更提醒

### 亮点四：安全审计体系
- **全操作记录**：记录所有用户操作
- **责任追踪**：记录操作人、时间、IP地址
- **合规要求**：满足政务系统审计标准

### 亮点五：响应式前端设计
- **CSS变量主题**：统一管理样式
- **Flexbox/Grid布局**：适配不同屏幕
- **B站风格**：现代化个人主页设计

## 📊 数据库设计（2分钟）

### 核心表结构
| 表名 | 用途 | 关键字段 |
|------|------|----------|
| users | 用户信息 | id, username, password, department, last_login_time |
| departments | 部门信息 | id, name |
| news | 新闻内容 | id, title, content, category, status |
| blogs | 博客内容 | id, user_id, title, content, status |

### 设计特点
- **统一用户表**：合并前后台用户
