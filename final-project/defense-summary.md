# 政务数字门户平台 — 答辩材料

---

## 一、项目概述

**项目名称**：政务数字门户平台 POC  
**技术栈**：Python Flask + MySQL + Docker + HTML5/CSS3/JavaScript  
**部署环境**：openEuler 22.03 LTS 虚拟机  
**核心功能**：统一认证、用户管理、部门管理、新闻管理、博客系统、反馈管理、系统监控

---

## 二、核心功能模块

| 模块 | 功能描述 |
|------|----------|
| **统一认证** | 管理员/普通用户登录、注册、Session管理 |
| **用户管理** | 用户CRUD、个人信息编辑、最后登录时间记录 |
| **部门管理** | 管理员动态增删改部门，注册时可选部门 |
| **新闻管理** | 政务新闻增删改查、分类筛选、搜索、快速发布/草稿 |
| **博客模块** | 发布博客（含图片）、审核流程、评论、点赞、好友系统 |
| **反馈管理** | 提交反馈、管理员处理回复、类型/状态筛选 |
| **系统监控** | 运行时间、请求计数、数据库统计 |
| **操作日志** | 全操作审计日志 |

## 四、数据库表设计

|------|------|
| users | 用户信息（统一前后台） |
| departments | 部门信息 |

| feedback | 用户反馈 |

| friends | 好友关系 |

---

## 五、关键技术亮点

1. **Docker 容器化部署**：一键部署脚本，10分钟完成环境搭建
2. **统一认证系统**：管理员与普通用户共用登录接口
3. **博客审核流程**：普通用户发布需审核，管理员直接发布
4. **操作审计日志**：记录所有操作，支持安全追溯
5. **响应式前端设计**：适配多种屏幕尺寸
