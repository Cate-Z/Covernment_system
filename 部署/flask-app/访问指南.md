# 政务数字门户平台 - 访问指南

## 一、平台概述

政务数字门户平台是基于 Flask + MySQL 构建的政务服务管理系统，提供新闻管理、政务服务、用户反馈等核心功能。

## 二、访问地址

### 本地访问
- **URL**: http://localhost:5001
- **端口**: 5001

### 容器信息
- Flask应用容器: gov-portal-flask (端口映射: 5001->5000)
- MySQL数据库容器: gov-portal-mysql (端口映射: 3308->3306)

## 四、功能模块

### 1. 首页
- 统计概览：新闻数量、服务数量、反馈数量、待处理数量
- 最新政务动态展示
- 热门政务服务展示
- 用户反馈入口

### 2. 新闻管理
- 新闻列表展示（支持搜索、分类筛选）
- 添加/编辑/删除新闻
- 新闻分类：政策法规、政务动态、通知公告、办事指南、政务公开

### 3. 服务管理
- 政务服务卡片展示
- 添加/编辑/删除服务
- 服务类型：企业开办、税务办理、社保服务、医疗服务、教育服务、住房服务

### 4. 反馈管理
- 用户反馈列表（支持类型、状态筛选）
- 查看反馈详情
- 处理反馈（回复功能）
- 删除反馈

### 5. 用户管理
- 用户列表展示（支持搜索、状态筛选）
- 添加/编辑/删除用户
- 批量删除功能
- 导出用户数据（CSV格式）

### 6. 数据统计
- 用户统计：总数、活跃、非活跃、今日新增
- 部门用户分布图表
- 用户状态分布图表

## 八、数据库表结构

### users（用户表）
- id, name, email, phone, department, status, created_at

### news（新闻表）
- id, title, content, category, author, status, publish_time, created_at

### services（服务表）
- id, name, description, type, icon, sort_order, created_at

### feedback（反馈表）
- id, name, phone, email, type, content, status, reply, create_time, reply_time

## 九、注意事项

1. 确保Docker已正确安装并运行
2. 首次启动时会自动执行数据库初始化脚本
3. 管理员密码可通过系统设置进行修改
4. 建议在生产环境中关闭Debug模式
